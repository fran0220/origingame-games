# 奇幻迷宫塔防

## Context

玩家想要一款**自由布防**的浏览器塔防：地图格子均可建造，防御塔会**阻挡路径**，敌人用最短路奔向基地。胜负为**撑过全部波次获胜 / 基地血量归零失败**。主题为**西方奇幻（剑与魔法）**，画面为**2.5D 等距卡通**，难度**标准约 10 波**。操作上需要**多种塔 + 升级**，点击选位建造。

技术约束：本地 `index.html` + Three.js（vendor），无 CDN；需接入 OriginGame SDK（`ready` + progression `start` / `complete` / `fail`）。

## Approach

### 核心系统

1. **网格与寻路**  
   - 约 `12×10` 四向网格，单权威格子数据（占用、可建、出生点、基地）。  
   - 塔占 1 格并阻挡路径；放置/出售后用 **BFS** 重算路径。  
   - 放置校验：不得封死**每个出生点 → 基地**，也不得封死**场上每个敌人当前格 → 基地**；不可建在出生/基地/已有塔/敌人所占格/非可建地形。  
   - 敌人完成当前格间移动后再从下一格接新路径，避免瞬移与来回抽搐。

2. **三种塔 + 两级升级（基座 + 2 级）**  
   - **弓箭塔**：便宜、射速高、单体。  
   - **法师塔**：较慢、范围伤害。  
   - **冰霜塔**：低伤 + 减速控制。  
   - 点击格子建造；选中塔可升级/出售（约 60–70% 退款，不可套利）。  
   - 悬停幽灵塔、绿/红合法提示、射程圈、封路时明确提示「会堵住通路」。

3. **波次与经济**  
   - 约 **10 波**，逐步加压；杂兵 / 快跑 / 装甲 / 每隔数波小 Boss。  
   - 击杀金币 + 清波奖励；开局给足可试错的金币。  
   - 状态机：准备 / 波次进行 / 清波 / 胜利 / 失败 / 重开；防止波次重叠。

4. **表现**  
   - Three.js **正交等距**固定机位；清晰出生点、基地、血条、受击与减速反馈。  
   - 目录低模奇幻素材优先，不足处用 `generate_image` / `generate_audio`；核心玩法不依赖完美素材。  
   - HUD：金币、基地 HP、波次、建塔栏、升级/出售、开始下一波、重开；控件常驻可见。

5. **SDK**  
   - 首帧可玩后 `window.OG?.ready?.()`。  
   - 开局 / 通关 / 失败：`reportProgression` 的 `start` / `complete` / `fail`（幂等，重开不重复炸逻辑）。

### 资源策略

- 用 `origin_workbench_asset_search` / `assets_install` 检索安装低模奇幻塔、敌人、地形相关 GLB（若合适）。  
- 用 `generate_image` 生成 UI 图标、地块贴图、封面等 2D。  
- 用 `generate_audio` 生成建造、射击、击杀、受击、胜利/失败与轻量 BGM。  
- 全部接入游戏，不留未使用资源。

## Verification

- [ ] 可走迷宫式拉长路径，但无法完全封死出生点或场上敌人
- [ ] 波次中快速建/卖不导致卡死、无路径崩溃或重复实体
- [ ] 三种塔组合均可通关；升级与退款经济合理
- [ ] 胜利/失败可重开，无重复遥测异常、无残留敌人/塔
- [ ] 控件可见，窗口缩放正常，本地无外链
- [ ] workbench check 无 `og_ready_missing` / `og_progression_missing`
